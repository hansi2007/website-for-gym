# Sri Maruthi Power House Gym 24/7 💪

A modern, responsive gym website built to showcase Sri Maruthi Power House Gym in Jigani, Bengaluru, and help prospective members connect with the gym.

## ✨ Features
- Premium teal-and-white design
- Gym facilities and membership plans
- Gym joining enquiry form
- Supabase backend integration
- Admin dashboard for managing membership enquiries
- Google Maps directions and WhatsApp contact
- Responsive mobile and desktop layouts

## 📍 Location
2nd Floor, MNT Complex, No. 523, Jigani–Anekal Road, Vinayaka Nagar, Jigani, Bengaluru, Karnataka 560105.

## 🛠️ Tech Stack
- React + TypeScript
- Supabase (PostgreSQL and authentication)
- Google Maps integration

## 🚀 Setup
1. Clone this repository.
2. Install dependencies using `npm install`.
3. Configure your Supabase URL and publishable key in your local environment.
4. Apply the required database migrations.
5. Run `npm run dev`.

## 🔐 Security
Keep secret keys out of source control. Configure Row Level Security (RLS) and appropriate admin permissions before deployment.
